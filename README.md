# Sake Bar Natur - 90's Style Website

A retro 90's style single-page website for a sake bar, featuring sticky navigation, menu section, voting board for sake imports, and a message board.

Built with vanilla HTML/CSS/JS and Supabase for persistence.

## Features

- Sticky navigation to sections
- Menu display
- Voting board for sake suggestions
- Message board for guest messages
- 90's aesthetic with neon colors and animations

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Supabase (Backend as a Service)

## Development

1. Clone the repo
2. Run `pnpm install`
3. Run `pnpm dev` to start development server
4. Open `src/index.html` in browser

## Deployment

Deployed on Netlify/Vercel as static site.
